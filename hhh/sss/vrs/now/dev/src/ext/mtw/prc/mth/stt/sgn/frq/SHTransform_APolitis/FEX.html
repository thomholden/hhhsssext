Real/Complex Spherical Harmonic Transform and Gaunt Coefficients

by Archontis Politis

 

10 Oct 2013 (Updated 14 Oct 2013)

A small collection of routines for the Spherical Harmonic Transform and Gaunt coefficients.

| Watch this File

File Information
Description

This is a collection of MATLAB routines for the Spherical Harmonic Transform
of spherical functions, and some manipulations on the spherical harmonic domain.

Both real and complex spherical harmonics are supported. The orthonormalised
versions of SH are used. More specifically, the complex SHs are given by:
Y_{nm}(\theta,\phi)=\sqrt{\frac{2n+1}{4\pi}\frac{(n-m)!}{(n+m)!}}P_l^m(\cos\theta)e^{im\phi}

and the real ones as in:
http://en.wikipedia.org/wiki/Spherical_harmonics#Real_form

For the complex basis Matlab Legendre's function should be extended for negative
orders m<0. This is done in Legendre2 function.

Furthermore, there is a routine for calculation of Gaunt coefficients, useful in evaluation of the coefficients of products of spherical functions. The formula used for the calculation of the Gaunt coefficients is based on Wigner3j symbols, as given in :
http://en.citizendium.org/wiki/Spherical_harmonics#Gaunt_series

For the calculation of the Wigner3j symbols, the function by J. Pritchard found at:
http://massey.dur.ac.uk/jdp/code/w3j.m
is used.
Note that line 20&21 should be removed for our general case.

Required Products MATLAB
MATLAB release MATLAB 8.1 (R2013a)

@ Simone Winkler:

Hi, probably you have figured that by now, it should be also in the help description of the leastSquaresSHT.m and weightedLeastSquaresSHT.m. You can convert your cartesian coordinates to spherical ones and omit the radius, then pass the values along with their respective directions. More precisely:

F = [value1; value2; ...]
dirs = [azimuth1 inclination1; azimuth2 inclination2; ...]

where:

[F_N, Y_N] = leastSquaresSHT(N, F, dirs, basisType);
