New features:
- unsteady Navier-Stokes solver
- semi-implicit backward-Euler (SIBE) and second order semi-implicit Adams-Bashforth/Backward Differentiation (ABBD2) time integrators
- a posteriori error estimation using the spectral coefficients
- various visualization methods (mesh, surface, vector, streamline)
- barycentric Lagrange interpolation instead of interp2 for speedup and better stability

Fixes:
- vorticity is now calculated on the boundary
- less function overhead due to careful preprocessing
- revised help
- both numeric arrays and function handles are allowed for the boundary conditions
- helper function for the boundary conditions
- Kronecker-product is eliminated from partialder.m -> much faster
- further improvements
