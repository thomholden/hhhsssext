
animateLaTeX for Matlab
_______________________

This is animateLaTeX for Matlab. Both "animateinlineLaTeX" and "animategraphicsLaTeX"
are programs that creates source code for animations in LaTeX.

In runAllExamples.m you will find some examples.

"animateLaTeX.pdf" is a compiled pdf example and "animateLaTeX.tex" is its LaTeX source code
(excluding the animations that are created by the m-file examples).

Run "runAllExamples" in Matlab and then compile "animateLaTeX.tex" and you will have a brand new pdf with animations.

The Matlab script "delAni" deletes files created by animateLaTeX in the current folder and might
be useful after animations are created.
