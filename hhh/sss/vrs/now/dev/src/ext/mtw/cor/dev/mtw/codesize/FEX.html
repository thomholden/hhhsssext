CodeSize

by Yair Altman

 

06 Jul 2007 (Updated 10 Jul 2007)

display information about the code size of a given source file or project folder

| Watch this File

File Information
Description

CodeSize displays information about the number of files/lines/characters within a given source file (*.m/c/h/java), function handle or project folder. CodeSize segments the results into comments and non-comments.

Now you can brag to your boss or client that your source code has a total of 2MB, with 40K lines, 25% of which are comments.

See contained help for usage and known issues/limitations.

Bugs and suggestions:

11 Jul 2007 John D'Errico

My sincere thanks to the author for fixing some issues with the code from its first release. He has improved it nicely.

Complete help, with examples of use. An H1 line. Error checks. Internal comments. Well done.

For those of you who use this code, I'll suggest a rough aim should be to have 50% of your m-files as comment lines. Liberal (meaningful) comments will be very much appreciated by you or anyone who tries to read your code in the future to understand how it works, or when you need to fix a bug one day. Use white space too. It improves the readability of your code.
