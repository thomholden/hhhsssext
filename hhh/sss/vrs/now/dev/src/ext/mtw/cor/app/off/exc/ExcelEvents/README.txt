
This file describes the "Global Temperature Explorer" application from
the Sept. 2006 MATLAB News & Notes article "Handling MATLAB Events in Excel."
It contains an overview of the application, a list of the files
comprising the application and instructions on how to build the
application and integrate it into a Microsoft Excel spreadsheet.

In order to use these files, you'll need MATLAB, the MATLAB Compiler, 
MATLAB Builder for .NET and Microsoft Excel. This application has been
tested on Windows XP, Service Pack 2. It will probably work on your
machine if you have that configuration. Your mileage may vary on other
versions of Windows.

If you have questions or comments, feel free to contact me at
pwebb@mathworks.com.

Overview:

The application consists of two parts, a COM component generated by
MATLAB Builder for .NET, and a Visual Basic class module that
integrates the COM component into Excel. The COM component consists of
M-files and data files; it displays a data navigation GUI and exports
two events: "DisplayLocation" and "PlotTempData". The Visual Basic
code contains callbacks that respond to the exported events and a
macro used to launch the data navigation GUI.

Manifest:

README.txt           : This file.
GlobalTemp.m         : The main M-file.
DisplayLocation.m    : Callback for "DisplayLocation" event.
PlotTempData.m       : Callback for "PlotTempData" event.
TempAnomData1880.mat : Global temperature history data.
Cities.csv           : List of city names and geographic coordinates.
TempAnomaly.cls      : Visual Basic code integrating COM component into Excel.
TempAnomTool.bas     : Visual Basic macro for launching the GUI in Excel.

Building the COM Component:

Use the MATLAB Compiler (either in MATLAB or at the DOS command line)
to build the COM component from the files in this download.

mcc -W com:GlobalTemp,GlobalTempClass,1.0 -T link:lib GlobalTemp
       DisplayLocation PlotTempData -a TempAnomData1880.mat -a Cities.csv


Integrating the COM Component into Excel:

Make sure you generate the COM component before performing these
steps; if you don't the COM component will not be registered, and
you'll be unable to 

1. Start Microsoft Excel

2. Open the Visual Basic Editor ( Tools | Macros | Visual Basic
   Editor).

3. Add a reference to the GlobalTemp 1.0 Type Library ( Tools |
   References ). If this type library is not available, be sure that your
   MCC command completed without errors.

4. Import the TempAnomaly.cls class file. (In the Visual Basic
   project window, right click the project and select Import File. Choose
   TempAnamoly.cls.)

5. Import the TempAnomTool.bas file. (Use the same process as step 4,
   only this time select TempAnomTool.bas instead of TempAnamoly.cls.)

Using the Global Temperature Explorer:

You run the Global Temperature Explorer by executing the
LaunchTempAnomGUI macro that you imported in step 5 of the previous
section. 

1. From an empty Excel spreadsheet in the current workbook,
   select Tools | Macro | Macros... and run LaunchTempAnomGUI.

2. Wait...

3. When the data navigation GUI appears (a globe), select a city
   from the list on the left. The globe rotates to display a red dot
   on that city and a series of green dots around the city.

4. Select one of the dots to view the temperature history for that 5x5
   degree portion of the Earth. The length of the time series varies
   for each location on the globe. In some places records go back as
   far as 1880.

If you'd like to generate multiple temperature history graphs for
different sections of the globe, use a new spreadsheet for each
graph. You don't need to relaunch the data navigation GUI -- the
application creates its graphs on the currently active spreadsheet.
