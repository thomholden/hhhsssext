File Information
Description

Here is an slightly updated version 2 of H.264 (also known as MPEG 4 AVC) baseline codec. It includes I, P frames, CAVLC coder, Exp Golomb Coder, integer transform and other basic functionalities of H.264 or MPEG-4 AVC (Advanced Video Coding). I have uploaded another version before. But users were having difficulty with finding/reading UVC files and therefore, this version reads sequence of video frames (sample provided as well - Foreman QCIF). You can modify the image reading mechanism if you need to.

Acknowledgements

This file inspired H.264 Baseline Codec [Reading And Writing Videos].
Required Products MATLAB
MATLAB release MATLAB 7.11 (R2010b)
