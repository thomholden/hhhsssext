Instructions for the Marine Visualization Toolbox
-------------------------------------------------------


To INSTALL the Marine Visualization Toolbox:
1.	Make sure that the following files are located
	in the same folder:
		MVT_toolbox.zip
		MVT_help.zip
		MVTinstall.m
2. 	Run the installation file in MATLAB by typing:
		MVTinstall


To UNINSTALL the toolbox:
Run the installation file with the argument 'uninstall' 
by typing:
		MVTinstall('uninstall')
