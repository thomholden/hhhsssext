+-------------+
| GET STARTED |
+-------------+

Before executing segm_energyLS.m in each Matlab session run once 
the ini.m file, for proper paths.

Choose the initialization method (in the options panel), then load
an image (Load/Save menu).
If initialization is set on manual, then draw a multi-polygonal 
partition with the mouse. R-click to end a contour, Esc to end drawing.

Then choose segmentation parameters:
 Mu, Lambda+ / Lambda- , dt, Nu 

In case you don't have bwdist.m then use the built-in redistancing function. 
(options panel)

For more info see the "Menus", "Buttons/Options" and the "Workflow" sections.
